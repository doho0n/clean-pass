# 무인 음주단속 시스템

> ESP32와 ESP32-CAM을 활용하여 차량 감지, 음주 측정, 번호판 및 신분증 촬영, Gmail 알림 전송까지 수행하는 **무인 음주단속 시스템**입니다.

---

## 프로젝트 소개

음주운전은 심각한 사고와 인명 피해를 유발하는 사회적 문제입니다.  
본 프로젝트는 기존 음주단속 과정에서 발생하는 **경찰 인력 부족 문제**와 **현장 위험 요소**를 줄이기 위해 기획된 **무인 음주단속 시스템**입니다.

이 시스템은 차량을 감지하면 자동으로 번호판을 촬영하고, 운전자에게 음주 측정을 안내합니다.  
측정 결과에 따라 정상 운전자는 통과시키고, 음주가 감지된 경우에는 신분증을 촬영한 뒤 Gmail을 통해 알림을 전송하도록 설계되었습니다.

---

## 개발 목적

- 음주단속에 필요한 인력 소모 최소화
- 음주운전 예방 및 사고 발생 가능성 감소
- 실제 환경에서 동작 가능한 하드웨어 기반 시스템 구현
- ESP32, ESP32-CAM, 센서를 연동한 자동 단속 프로세스 구현

---

## 문제 배경

현장 인터뷰를 통해 다음과 같은 필요성을 확인했습니다.

- 음주단속은 매일 이루어짐
- 12명의 인원이 3인 1조 교대로 담당하여 인력 부담이 큼
- 비협조적인 운전자 대응 과정에서 경찰관이 위험에 노출될 수 있음

따라서 반복적이고 위험한 일부 절차를 자동화할 수 있는 시스템의 필요성이 높다고 판단했습니다.

---

## 주요 기능

### 1. 차량 감지 및 번호판 촬영
- 초음파 거리센서를 이용해 차량 접근 감지
- 일정 거리 이내로 차량이 들어오면 ESP32-CAM으로 번호판 촬영
- 촬영 이미지는 Google Drive로 전송

### 2. 음주 측정 안내
- LCD 화면을 통해 운전자에게 음주 측정 절차 안내
- LED 색상으로 현재 상태 표시
- 유량센서를 통해 충분한 호흡이 입력되었는지 확인

### 3. 알코올 측정
- MQ-3 알코올 센서를 이용해 음주 여부 판별
- 기준값에 따라 정상 운전자 / 음주운전자 분기 처리

### 4. 신분증 촬영
- 음주운전자로 판단될 경우 버튼 입력 후 신분증 촬영
- ESP32-CAM을 활용해 이미지 저장

### 5. 이메일 전송
- 음주 감지 시 ESP32와 Gmail 연동을 통해 메일 발송
- 후속 조치를 위한 자동 알림 기능 수행

### 6. 바리게이트 제어
- 정상 운전자 또는 처리 완료 시 서보모터를 이용해 바리게이트 동작

## 동작 시나리오

1. 차량이 시스템 앞에 접근
2. 초음파 센서가 차량을 감지

7. 결과에 따라 분기 처리

## 회로 구성

### ESP32-CAM + HC-SR04
- GPIO 12 → HC-SR04 TRIG
- GPIO 14 → HC-SR04 ECHO

### ESP32-CAM + 버튼 모듈
- GPIO 12 → 버튼모듈 OUT

### ESP32 + 주변 센서/모듈
- GPIO 13 → 서보모터
- GPIO 15 → 유량센서
- GPIO 18 → HC-SR04 TRIG
- GPIO 19 → HC-SR04 ECHO
- GPIO 21 → LCD SDA
- GPIO 22 → LCD SCL
- GPIO 23 → LED
- GPIO 34 → 알코올 센서 OUT

## 트러블슈팅

### 1. ESP32-CAM 단독 사용 시 핀 부족 문제
**문제**  
ESP32-CAM 하나만으로 모든 센서를 연결하려고 하니 핀이 부족했습니다.

**해결**  
ESP32-CAM은 촬영 전용으로 사용하고, 나머지 센서 제어는 ESP32가 담당하도록 역할을 분리했습니다.

---

### 2. 센서 추가 과정에서 전류 이상 발생
**문제**  
센서를 하나씩 추가하는 과정에서 시스템 동작이 불안정해졌습니다.

**해결**  
각 센서의 전류를 개별적으로 점검했고, 문제가 있던 RGB LED를 LED Ring으로 교체하여 안정성을 확보했습니다.

---

### 3. 전류 부족 문제
**문제**  
전원이 약하게 공급되어 전체 시스템 동작에 문제가 발생했습니다.

**해결**  
기존 AVR 전원공급기를 더 안정적인 전원 장치로 교체하여 문제를 해결했습니다.

## 프로젝트 수행 후기

본 프로젝트는 원래 3인 1조로 시작되었지만, 팀원 2명이 중도에 빠지면서 최종적으로 **혼자 프로젝트를 수행**했습니다.  
초기에는 ESP32-CAM으로 촬영한 이미지를 서버에 저장하고 이를 확인할 수 있는 애플리케이션 설계를 담당했지만, 이후에는 기획, 개발, 테스트까지 전 과정을 단독으로 진행했습니다.

- 프로젝트 관리 능력
- 하드웨어/소프트웨어 통합 개발 역량
- 문제 해결 능력
- 끝까지 완수하는 책임감과 끈기
